# 📘 Техническое задание (ТЗ)
## Мини-игра "Memory / Match Pairs"

---

## 1. 📌 Общая концепция

Игра реализует классическую механику поиска пар:

- Игрок открывает карточки
- Необходимо находить одинаковые пары
- Цель — открыть все пары за минимальное количество попыток

---

## 2. ⚙️ Функциональные требования

### 2.1 Игровое поле

- Размер сетки: 4x4
- Общее количество карточек: 16
- Количество уникальных элементов: 8 (каждый повторяется дважды)
- Карточки:
  - изначально скрыты
  - перемешиваются случайным образом при каждой новой игре

---

### 2.2 Механика игры

#### Открытие карточек

- За один ход можно открыть только 2 карточки
- При клике:
  - карточка "переворачивается"
  - показывается символ (например, emoji)

---

#### Проверка совпадения

- Если карточки совпадают:
  - остаются открытыми
  - получают статус matched
- Если не совпадают:
  - закрываются через 600–800 мс

---

### 2.3 Ограничения

- Нельзя открыть более 2 карточек одновременно
- Нельзя кликать во время проверки пары
- Нельзя нажимать на уже найденные пары
- Нельзя повторно нажимать одну и ту же карточку

---

### 2.4 Система подсчёта

- Попытки (attempts):
  - увеличиваются при каждой проверке пары

- Счёт (score):
  - увеличивается при нахождении совпадения

---

### 2.5 Условие победы

- Все пары найдены (score = 8)
- После победы:
  - отображается сообщение (alert или модальное окно)
  - показывается количество попыток

---

### 2.6 Перезапуск игры

- Кнопка "Новая игра"
- При нажатии:
  - поле очищается
  - карточки перемешиваются заново
  - счёт и попытки сбрасываются

## 4. 🧠 Архитектура и логика

### 4.1 Состояние игры

Необходимо хранить следующие переменные:

firstCard   — первая выбранная карточка  
secondCard  — вторая выбранная карточка  
lockBoard   — блокировка ввода  
score       — количество найденных пар  
attempts    — количество попыток  

---

### 4.2 Основной алгоритм

1. Создание массива карточек:
   - взять список символов
   - продублировать
   - перемешать

2. Рендер карточек в DOM

3. Обработка клика:
   - открыть карточку
   - сохранить выбор

4. После выбора двух карточек:
   - увеличить attempts
   - сравнить значения

5. Если совпали:
   - пометить как matched
   - увеличить score

6. Если не совпали:
   - закрыть через таймер

7. Проверка победы

---

### 4.3 Перемешивание (Shuffle)

Допустимый вариант:

array.sort(() => Math.random() - 0.5)

Рекомендуемый (для продакшена):
- алгоритм Fisher-Yates
